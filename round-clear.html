GRAND FINAL — Clear a Round

Use this only for a last-minute fix on one round. It never touches any other round, and never touches Attendance.

Option A — Clear results only

Keeps the board pairings (who's playing who) for this round. Wipes the entered result, remarks, flags. Use this if the pairings for the round are correct but a result was entered wrong and needs redoing.

Option B — Clear pairings + results (full reset)

Wipes everything for this round: who's playing who, and any results. Boards go back to blank (TBD) so the Chief Arbiter can re-paste the correct pairing. Use this if the round itself was set up wrong.
